# F-018: 资料页与岗位库视觉对齐

## Goal

以用户确认后的投递看板为唯一正式样例，让岗位库、简历版本、网申档案和个人档案共享其内容起点、卡片边距、筛选/分隔节奏与柔和表格视觉。

## User scenarios

1. 用户切换到资料页时，内容从顶栏下方的统一位置开始，不再出现额外的大页面标题。
2. 用户在岗位库看到与投递看板相同的表格承载形式，以及明确的等待导入状态。
3. 用户在资料页继续使用原有保存、生成、选择和编辑交互。

## In scope

- 对齐岗位库、简历版本、网申档案和个人档案的前端布局与样式。
- 新建只读的岗位库视觉骨架和导航入口。
- 移除上述页面的大 `h2` 标题，改为轻量模块标签。

## Out of scope

- 不实现岗位数据导入、外部文档同步、岗位搜索 API 或筛选逻辑。
- 不改变简历、档案的 API、保存逻辑、数据模型或 AI 能力。

## Acceptance criteria

1. 四个页面使用和投递看板一致的内容边距、卡片圆角、卡片内边距与细分割线。
2. 四个页面没有独立的大 `h2` 模块标题。
3. 岗位库可从侧栏进入，展示表格列与“等待导入岗位信息”的非交互状态。
4. 现有资料页保存、创建、生成和编辑入口不变。
5. `vue-tsc --noEmit` 通过。
6. 投递表格、简历版本和个人档案的内容面使用统一的透明白色；个人档案分为“个人信息”和“教育背景”，紧急联系人字段归入个人信息。
7. 网申档案的“新建网申档案”位于顶部说明右侧、样式与保存按钮一致；档案名称与适用标签控件顶部对齐。
8. 个人档案与网申档案使用固定宽度的标签列；同一列的所有输入控件左侧对齐、宽度一致。

## Affected contracts

- 无：仅前端布局与导航占位页，不新增数据调用。

## Risks and open questions

- 岗位库的字段和导入来源将在后续独立 Feature 中确定；当前不得展示虚构岗位数据。
