# F-008: 工作台内容区布局统一

## Goal

移除资料维护页面的冗余页首说明，并让简历优化、网申资料和个人资料使用完整可用宽度。

## User scenarios

1. 用户进入简历优化、网申资料或个人资料时，直接看到当前页面的实际操作卡片。
2. 宽屏下，表单和卡片不再受 `max-w-5xl` 或 `max-w-6xl` 限制。

## In scope

- 三个页面外层内容区保持 `w-full max-w-none`，但页面内直接承载表单的卡片以居中最大宽度和响应式左右内边距呈现。
- 删除这三个页面最顶部的页面标题和说明段落。

## Out of scope

- 不改变侧栏、顶部栏、表单字段、卡片内容、接口、数据或交互。

## Acceptance criteria

1. 三个页面不显示对应的顶部 `h1`/说明文字。
2. 三个页面的外层内容区在工作台主栏中全宽布局，但卡片在宽屏不无限拉长，并保留一致的响应式边距。
3. 工作台类型检查通过。

## Affected contracts

- 无；本项不改变数据、API 或扩展行为。

## Risks and open questions

- 宽度增大可能改变卡片换行，但不应影响表单功能。
