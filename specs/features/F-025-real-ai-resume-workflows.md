# F-025 真实 AI 简历工作流

## 目标

把岗位评估、投递材料、整份简历优化和所选素材卡片的 JD 定向改写，从 Mock/本地排序器切换为当前用户配置的 OpenAI-compatible Provider，并补齐参考简历所需的教育字段与紧凑 A4 布局。

## 已确认范围

- 教育记录支持学校、专业、学历、学位、GPA、GPA 满分、专业排名、校园职务、起止年月；结束时间允许“至今”。
- 教育模块只出现一个标题并保留顶部细分隔线；所有经历卡片无左侧蓝线、无色块。
- 真实 AI 可接收用户本次明确发起工作流所需的已保存 JD、临时简历文本、求职偏好、最近评估结果，以及明确选中的卡片文案/facts。
- 目标端点为 AI 设置中当前显示的 baseUrl（当前配置为 `https://api.deepseek.com`）。不得发送照片、证件号码、Cookie、DOM、页面已有值或未选择的素材。
- 所有模型结果必须经 Zod 校验；网络、鉴权、模型或结构错误返回可恢复的稳定错误，不回退 Mock。
- AI 只生成预览。保存投递材料、简历版本和卡片 variant 仍需用户显式确认；历史版本不可覆盖。

## 验收标准

1. 四个简历相关工作流均返回实际 provider/model，不再出现 `MOCK`、`LOCAL_GROUNDED` 或 local 模型名。
2. 岗位评估仍写 AgentRun 摘要与结构化结果，不持久化完整 resumeText；失败运行可审计。
3. 投递材料和整份简历优化为零写入预览，用户保存后才创建记录。
4. 卡片改写只处理请求中已验证归属的 card/variant，返回集合必须与输入一一对应；新增数字事实会被服务端拒绝。
5. API Key 只在服务端内存中用于 Authorization，不进入日志、响应或数据库。
6. 教育参考布局和无左侧蓝线样式通过服务测试、类型检查和构建。
