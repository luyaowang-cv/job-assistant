# F-004：简历优化中心与版本管理

## Goal

提供独立的“简历优化”页面，让用户主动保存一份基础简历；基于某条已保存岗位的 JD 生成可编辑的定制简历草稿，并在用户确认后创建可追溯的派生版本，永不覆盖基础版本。

## User scenarios

1. 用户从侧边栏进入“简历优化”，首次粘贴并保存一份基础简历。
2. 用户查看基础版本及已保存的定制版本，知道每个版本的来源岗位、时间和状态。
3. 用户选择一个未删除且含 JD 的 Application，系统以基础简历和 JD 生成定制简历预览。
4. 用户编辑预览内容，确认后另存为新的定制版本。
5. 用户打开任一历史版本，复制内容，或回到基础版本继续针对其他岗位生成。

## In scope

- 增加侧边栏“简历优化”与 `/resumes` 页面。
- 用户显式创建、查看、编辑和保存一份基础简历全文；此为 F-004 唯一允许持久化的完整简历原文。
- 一份基础简历可拥有多个不可变的定制派生版本；派生版本关联来源 Application 与 Job JD，不覆盖基础版本。
- 用户选择岗位后，使用基础简历、JD 和可选 F-002 评估生成完整定制简历预览；用户可编辑后主动保存为新版本。
- 版本列表展示名称、类型（基础/定制）、来源岗位、创建时间、Provider/模型和“是否用户编辑”。
- 当前版本可复制；基础版本和定制版本均支持在页面中手动编辑并保存为新版本。
- MVP 继续使用本地确定性 Mock Provider；无 API Key、无外部模型和无网络请求。

## Out of scope

- 上传 PDF/DOCX、解析文件、导出 PDF/HTML 或在线排版。
- 多份基础简历、简历模板市场、跨用户共享。
- 自动覆盖基础版本、自动投递或向招聘平台发送内容。
- 浏览器插件调用、职位爬取、Agent Chat、面试准备。
- 真实 LLM Provider、费用、外部数据传输。

## Acceptance criteria

1. 用户可以进入独立“简历优化”页面，首次可创建一份基础简历；同一 local user 最多有一个活动基础简历。
2. 基础简历全文只在用户明确点击保存时写入数据库；页面明确提示该保存行为与 F-002/F-003 临时简历输入不同。
3. 用户只能选择自己的、未软删除且有非空 JD 的 Application 来生成定制版本。
4. 生成预览不创建 ResumeVersion；用户主动点击保存后才创建一条新版本，基础版本永不被覆盖。
5. 一次定制预览返回完整简历文本、基于 JD 的修改摘要和事实依据；不得虚构用户经历、技能、数据或职位要求。
6. 保存的定制版本关联来源 Application；无 F-002 评估时仍能基于基础简历与 JD 生成。
7. 用户可查看、复制和编辑任一历史版本；对已保存版本的再次编辑创建新版本而不是原地覆盖。
8. 版本列表按创建时间倒序，并展示基础/定制类型、来源岗位、Provider/模型、用户编辑状态。
9. Mock Provider 标识为 `MOCK/local-resume-optimization-v1`，且无网络调用；真实 Provider 仅替换 Adapter。
10. Agent 不自动保存版本、不修改 Application 或材料历史；所有持久化简历内容由用户明确确认。

## Affected contracts

- `specs/contracts/domain-model.md`：新增 Resume、ResumeVersion、版本类型、来源 Application 和版本链约束。
- `specs/contracts/api-conventions.md`：定义基础简历、版本列表、定制预览和显式保存 API。
- `specs/contracts/agent-tools.md`：定义简历优化 preview 工具及其无副作用边界。

## Confirmed decisions

- 用户同意主动保存一份基础简历全文到本地 PostgreSQL。
- 不同 JD 基于该基础版本生成独立定制版本，不覆盖基础版本。
- F-004 是独立侧边栏页面；F-003 仍保留岗位详情内的轻量材料能力。
- 全文保存、版本创建和编辑保存均必须由用户明确点击确认。
- F-004 继续使用本地 Mock；不接真实模型、API Key 或外部请求。

## Risks and open questions

- 全文简历进入本地数据库后，需要在 UI 中清晰区分“永久基础简历”和“临时分析输入”。
- Mock 无法体现真实的高质量定制效果；后续接真实 Provider 前需确认模型、成本与数据传输授权。
- MVP 的“完整简历”采用纯文本编辑器；富文本、文件导入导出另列 Feature。
