# F-022: 首页响应式卡片网格

## Goal

让首页在固定侧栏下的不同显示器宽度保持可读卡片宽度和一致的 16px 网格间距。

## User scenarios

1. 用户在大屏、笔记本和较窄桌面显示器中查看首页时，统计卡不会被压缩到不可读。
2. 用户缩放窗口时，今日重点和行动轨迹会在合适宽度堆叠，而不发生横向溢出。

## In scope

- 为首页概览与工作区补充中等桌面及窄桌面断点。
- 固定各布局档位的卡片间距为 16px。
- 记录首页响应式规则到 UI 开发基准。

## Out of scope

- 不改变首页文案、数据、交互或卡片视觉风格。
- 不改变侧栏的现有折叠策略。

## Acceptance criteria

1. 大屏保留四列概览和左右双栏工作区。
2. 1280px 以下，重点卡整行，三张统计卡等宽；1120px 以下，工作区单列。
3. 900px 以下，概览单列；所有档位无横向溢出。
4. 各档位卡片之间的水平或垂直间距均为 16px。
5. Sass 编译通过。

## Affected contracts

- 无。

## Risks and open questions

- 固定侧栏使视口宽度与实际内容宽度不同，因此断点需按可用内容区验证。
