# 求职工作台 UI 开发基准

本文件是后续页面开发与 UI 评审的唯一视觉基准。实现以 [web/app/assets/scss/index.scss](../web/app/assets/scss/index.scss) 中的 `:root` token 为唯一代码来源；新页面不得复制旧页面的具体色值、圆角或间距。

## 设计方向

求职工作台采用低对比、暖白表面与灰绿操作色。页面背景、内容卡片、实体控件应形成清晰的三层关系：背景承载氛围，卡片组织内容，输入框和表格承载可编辑或可扫描的信息。

## Token

| 用途 | Token / 值 | 使用规则 |
| --- | --- | --- |
| 主文字 | `--workbench-ink` / `#3d464b` | 标题、正文、输入值 |
| 常规文字 | `--workbench-slate` / `#64716d` | 说明文字、次级信息 |
| 表单标签 | `--workbench-subtle` / `#52605b` | 标签不得使用更浅的灰色 |
| 页面底色 | `--workbench-mist` / `#f2f3f0` | 仅用于页面背景 |
| 卡片表面 | `--workbench-solid` | 内容卡片与信息分组 |
| 控件表面 | `--workbench-control` | 输入、选择、数字输入、表格实体区域 |
| 控件边界 | `--workbench-border` | 输入与表格的默认边框 |
| 焦点环 | `--workbench-focus` | 仅用于键盘/编辑焦点 |
| 主操作 | `--workbench-blue` / `#7a9689` | 每个页面仅一个主要提交或新建操作 |
| 主操作按下/悬停 | `--workbench-blue-deep` / `#668476` | 主操作的交互状态 |
| 成功状态 | `--workbench-green` / `#8fba9e` | 成功反馈与状态，不替代主操作 |

## 尺寸与间距

只使用以下间距刻度：`4 / 8 / 12 / 16 / 24 / 32px`，对应 `--space-1 / 2 / 3 / 4 / 6 / 8`。

| 元素 | 规则 |
| --- | --- |
| 主卡片 | 16px 圆角，24px 内边距 |
| 输入、选择、数字输入 | 40px 高，10px 圆角 |
| 主按钮 | 40px 高 |
| 工具按钮 | 32px 高；例如搜索、重置、视图切换 |
| 表单行 | 40px 控件高，行间距 16px |
| 双列表单 | 两列之间 32px；标签宽 112px，标签与控件间 12px |
| 区块分隔 | 24px 上间距与内边距，配合细分割线 |

不要使用任意的 `6、9、11、13、14、19、20、22、28px` 圆角或间距。出现新的尺寸需求时，应优先组合既有刻度；只有形成新的全局 token 时才可新增。

## 可复用结构

- `page-rail`：页面内容轨道；用于控制可读宽度。
- `material-surface`：主内容卡片；不要在其内部再无意义地套同等级卡片。
- `material-surface__header`：卡片标题、说明和唯一主操作。
- `material-section-label`：卡片内部的区块标题与分隔线。
- `profile-form-grid`：档案类双列表单；全宽字段加 `profile-form-item--wide`。
- `profile-form-row`：带固定标签宽度的单行表单。
- `workbench-table-shell`：表格实体容器；表头必须保留可区分的背景和文字对比度。

## 操作层级

- 一个页面的主要“新建、保存、生成、提交”操作使用实心绿色主按钮，且同一视图中只保留一个。
- 次级操作使用朴素按钮，不使用主操作的阴影或填充色。
- “重置”使用绿色系次级样式，不使用紫色。
- 删除使用低强调的危险朴素按钮，保持在所属条目的右侧；不得与保存或新建竞争视觉权重。
- 列表/看板切换仅以边框与文字/图标颜色标识激活状态；悬停不使用紫色背景或放大动画。

## 文本、边框与状态

- 正文和输入文字使用 14px；标签 13px；辅助文字、表头和状态说明 12px。
- placeholder、辅助文字和表头必须保持可读；不要用几乎与背景相同的浅灰色。
- 输入框必须比卡片更实，保持暖白底、清晰边界，并提供焦点环。
- 动效只可辅助理解。列表卡片悬停可改变边框或底色，不可缩放放大。

## 响应式布局

- 页面内容轨道使用 `width: min(100%, …)`，不得将卡片宽度写死为某个显示器尺寸。
- 当固定侧栏压缩主内容区时，首页使用三档布局：大屏为“重点卡 + 三张统计卡”和左右双栏；中等桌面为重点卡整行、三张统计卡等宽；较窄桌面与手机为单列。
- 所有网格档位维持 16px 卡片间距；发生换行时使用同一间距，不额外叠加页面专属 margin。
- 网格项必须使用 `minmax(0, 1fr)` 或明确的可缩小尺寸；禁止以固定最小宽度导致主内容横向溢出。

## 实现约束

1. 全局 token、Element Plus 主题变量和通用组件规则统一维护在 `web/app/assets/scss/index.scss`。
2. 页面差异必须以语义化页面类做局部覆盖，例如 `.application-profile__saved`；禁止用全局 Element Plus 选择器修复单个页面。
3. 开发新页面前先复用本文件的结构类和 token；发现可跨页面复用的规则，再添加到 `index.scss`，不要创建第二套 UI 入口。
4. 改动表单或表格后，至少在桌面和窄屏检查控件高度、左右边界、换行和横向溢出。
